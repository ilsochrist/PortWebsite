Data Lakehouse Medallion: Sentimento e Governança com Databricks.

Foi utilizado: Databricks, Power BI, jupyter notebooks, jobs, text analysis

Objetivo: Implementar um Data Lakehouse escalável e seguro para transformar dados brutos de notícias/streams em insights acionáveis, utilizando a arquitetura Medallion para governança e qualidade.

A Solução:
A Arquitetura Medallion foi implementada para garantir a confiabilidade e governança dos dados em todo o pipeline, com foco em segurança e controle de acesso por camada..

1. Bronze (Raw):
Função: Ingestão de dados brutos e imutáveis. Resultado: Fonte de verdade para auditoria e reprocessamento.

2. Silver (Cleaned & Enriched):
Função: Limpeza, padronização e enriquecimento do dado. Enriquecimento: Implementação de UDFs para Análise de Sentimento e engenharia de features (ex: Top Keywords, Nível de Complexidade). Qualidade: Monitoramento da Latência de Ingestão e aplicação de regras de Qualidade de Dados.

3. Gold (Curated & Consumption):
Função: Modelagem final do dado, otimizado para leitura. Consumo: Dados estruturados prontos para a criação de dashboards e relatórios no Power BI. Impacto: Transformação de dados textuais não estruturados em KPIs de negócio (Sentimento) através de um pipeline automatizado com Databricks Jobs, garantindo que as decisões de BI sejam baseadas em dados seguros e de alta qualidade.

Concluí com sucesso a transformação de dados brutos e complexos em informação estruturada (Delta Lake), e foi consumido de forma estratégica e escalável pelo Power BI. Este pipeline estabelece a fundação para análises avançadas e tomadas de decisão proativas baseadas em fatos.

Azure AI Exam Analysis

Azure AI Exam Analysis, utilizando: Power BI, Azure AI Document Intelligence, Azure Blob Storage, Python, o SDK Python azure-ai-formrecognizer, e as bibliotecas Python csv, os, e python-dotenv.

Objetivo: Instituições de saúde e pacientes acumulam anos de exames em formato PDF. Esses documentos contêm informações vitais, mas são, em essência, "silos de dados" difíceis de consultar, comparar e analisar em conjunto. Como poderíamos destravar o valor contido neles de forma escalável?

A Solução:
Para resolver esse problema, implementei uma arquitetura de dados inteligente na nuvem da Microsoft Azure.

1. Centralização em um Data Hub Seguro::
Um repositório central foi criado no Azure Blob Storage.

2. Extração Inteligente com IA:
Utilizei o Azure Document Intelligence para "ler" cada PDF de forma segura através das URLs SAS. O serviço de IA é treinado para identificar e extrair com precisão os dados-chave de cada exame: nome do paciente, datas, tipo de exame, métricas, resultados, etc.

3. Estruturação dos Dados:
coloquei as informações extraídas e agora estruturadas em um arquivo CSV padronizado. O arquivo ('resultados_exames.csv') é o resultado final, pronto para ser depositado em outro container no Blob Storage.

4. Extração Inteligente com IA:
Utilizei o Azure Document Intelligence para "ler" cada PDF de forma segura através das URLs SAS. O serviço de IA é treinado para identificar e extrair com precisão os dados-chave de cada exame: nome do paciente, datas, tipo de exame, métricas, resultados, etc.

Transformei um processo manual e demorado em um pipeline de dados automatizado, convertendo arquivos estáticos em insights acionáveis. Isso não apenas otimiza a gestão da informação, mas também abre um enorme potencial para análises preditivas e um cuidado ao paciente muito mais proativo e baseado em dados.

Azure AI Recipe Extractor

Azure AI Recipe Extractor, utilizando: Microsoft Azure, Azure AI Vision (OCR 'Read'), Python, Azure AI Vision SDK para Python, python-dotenv, Módulos Nativos do Python (os, sys, re).

Objetivo: Este projeto demonstra a aplicação de serviços cognitivos para transformar conteúdo visual não estruturado (imagem) em dados estruturados e prontos para uso. O foco foi a extração de uma receita, separando seus componentes (título, ingredientes e modo de preparo) com alta precisão.

1. Configuração no Azure:
O primeiro passo envolveu a criação e configuração do recurso Azure AI Vision (Cognitive Service) no portal do Azure, garantindo a obtenção segura do *Endpoint* e das Chaves de acesso necessárias para a comunicação via API.

2. Extração de Texto com OCR ('Read'):
No ambiente Python, o SDK do Azure AI Vision foi utilizado para aplicar o serviço de Reconhecimento Óptico de Caracteres (OCR), especificamente o recurso 'Read'. Este recurso é otimizado para extrair todo o texto da imagem, incluindo o corpo da receita do "Bolo de Leite".

3. Processamento e Estruturação (Tratamento da Camada de Dados Brutos):
Foi implementado uma camada de pós-processamento para transformar o texto bruto do OCR em dados utilizáveis. Isso incluiu:

• Identificação e separação do Título, Ingredientes e Modo de Preparo (Processamento e Estruturação).
• Destaque: Implementação de regras de tratamento de texto para garantir que caracteres especiais, como o símbolo de graus Celsius (°C), fossem corretamente reconhecidos e formatados, garantindo a integridade das instruções.

O resultado foi uma receita lida, processada e exibida de forma organizada no terminal.
